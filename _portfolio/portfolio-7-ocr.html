About This Work

This project aimed to improve accessibility in home healthcare by developing an OCR system for blood pressure monitors that recognizes seven-segment digits and automatically records systolic, diastolic, and pulse readings. The system was designed to help elderly users easily track their health data through a mobile interface.

Methodology

To support diverse blood pressure monitor designs, a custom dataset was built by synthesizing digit images (0–9) and combining them into realistic display samples. A YOLOX-based detection model was trained for seven-segment recognition and exported to ONNX format for lightweight deployment. The model was integrated into an Android app using JNI for real-time inference, automatically distinguishing between systolic, diastolic, and pulse values.

Major challenges included data scarcity, light reflections, shadows, and variations across different monitor displays. Through iterative fine-tuning and data synthesis, the system achieved robust performance suitable for home healthcare and digital therapeutics.

Results

The implemented system achieved high detection accuracy (95%) across multiple monitor types and lighting environments. The Android prototype successfully extracted and displayed readings in real time, allowing seamless data transfer to healthcare management applications. This system has since been integrated into several partner hospital apps in Korea, where it contributes to improving accessibility and independence among elderly users.

The system infers each digit individually and reconstructs the complete reading, allowing stable recognition despite variations in digit spacing and layout across different monitors.
