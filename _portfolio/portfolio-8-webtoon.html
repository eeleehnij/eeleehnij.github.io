About This Work

This project focuses on AI-based recognition and generation of Webtoon art styles. Using six Webtoons with distinct drawing styles, the models were trained to classify artistic patterns andgenerate new images that reflect each style’s unique visual characteristics.

Methodology

1. Data Preprocessing

Crawled Webtoon images were preprocessed using OpenCV to extract individual comic cuts. Techniques such as Canny Edge Detection, Morphological Transformations, and Hough Line Detection were applied to remove white backgrounds and isolate valid panels for training.

Classification

Implemented an image encoder and classification model to classify six distinct Webtoon styles. The model achieved 96.9% training accuracy and 95.9% test accuracy, demonstrating high performance in distinguishing drawing styles across titles.

Generation

Built a custom Webtoon face dataset through manual labeling and YOLOv5 detection. Trained DCGAN and StyleGAN2-ADA to generate Webtoon-style character faces. StyleGAN2-ADA, fine-tuned on 900 images, successfully generated realistic Webtoon faces using adaptive data augmentation.
