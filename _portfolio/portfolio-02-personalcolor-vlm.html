Overview of the proposed personal color analysis pipeline.

About This Work

This work studies vision-language models for personal color analysis. Personal color refers to an individual's most suitable color palette based on skin tone, hair, and eye color, and is widely used in the fashion and beauty domains. It builds on our earlier deep learning-based personal color classifier, which framed the task as plain image classification.

We construct PCVLM-DB, an instruction-tuning dataset for the task. Facial images from Deep Armocromia, FFHQ, and a kiosk dataset are aligned to a common label space — warm/cool and seasonal tones are retained while fine-grained subtype tones are discarded — and annotated by experts through collaborative decision-making, with a written rationale recorded for each decision. The resulting image, label and rationale triples are converted into image-text pairs using a predefined QA template and LLM paraphrasing.

Vision-language models (Qwen-VL, InternVL, LLaVA) are then fine-tuned on PCVLM-DB through visual instruction tuning, so that the model returns a personal color type together with the reasoning behind it rather than a bare class label.

The manuscript has been submitted to IEEE Access and is currently under revision.
