About This Work

Personal color analysis identifies the color palette that harmonizes with an individual's natural appearance — skin undertone, eye color, hair color — and guides choices in fashion, cosmetics, and styling. We propose PC-VLM, a domain-specific vision-language model for the task. Unlike a plain classifier, it returns both a personal color category and a written rationale grounded in the visual cues behind the decision. This work extends our earlier CNN-based personal color classifier, which produced a bare class label with no explanation.

PCVLM-DB

We construct PCVLM-DB, the first visual question answering dataset for personal color analysis: roughly 8,700 facial images paired with about 30,000 question-answer pairs. It integrates the public Deep Armocromia dataset, images sampled from FFHQ, and a proprietary set acquired from an industrial imaging source. Labels follow a three-level hierarchy: a warm/cool binary tone, four seasonal tones (Spring, Summer, Autumn, Winter), and eight fine-grained subtypes (Light, Bright, Mute, Deep). Three trained annotators labeled every internal image under the supervision of a domain expert, following a predefined decision flowchart; ambiguous cases were resolved by discussion and consensus. Annotators also wrote a rationale explaining each diagnostic decision, which is what allows the model to learn to explain rather than only predict. Image, label and rationale triples are then converted into image-text pairs using predefined QA templates, with LLM paraphrasing to diversify question phrasing while preserving meaning.

Visual Instruction Tuning

We fully fine-tune a range of pre-trained vision-language models on PCVLM-DB through supervised fine-tuning — Qwen3-VL, Qwen2.5-VL, InternVL3, InternVL2.5, and LLaVA-v1.5. Each model couples a vision encoder with a multimodal projector and an LLM decoder: visual features are projected into the language embedding space and processed jointly with text tokens under a standard next-token prediction objective. This adapts general-purpose multimodal models into domain experts that associate facial chromatic features with the diagnostic criteria used in personal color analysis.

Results

PC-VLMs outperform both conventional vision-only classifiers (ResNet, Swin, ViT backbones with a linear head) and zero-shot commercial multimodal models, with the largest margin on fine-grained subtype classification. The model is also noticeably more stable across classes, holding balanced performance where the vision-only and zero-shot baselines fluctuate sharply and collapse on the rarer winter subtypes. Beyond the numbers, the generated responses carry hierarchical reasoning: they name the warm/cool tone, the seasonal type, and the subtype, and justify each with the visual evidence the decision rests on.
