About This Work

This research focused on searching for new drug candidates to treat Alzheimer's Disease using machine learning methods. I collected bio-chemical data from PubChem and curate them to use for computational work. These curated datasets were used to train machine learning models to predict active compounds for potential therapy in Alzheimer's Disease.

Methodology

1. Data Collection

Using gene IDs associated with Alzheimer's disease, I collected compound datasets from PubChem, including SMILES codes, CID, activity labels, binding affinity (IC50), and additional metadata.

2. Data Curation and Feature Extraction

SMILES representations were processed using RDKit and converted into molecular fingerprints. Each molecule was encoded as a binary vector representing its chemical features.

3. ML-based Activity Prediction

Binary classification models (SVM, Logistic Regression, and Neural Networks) were trained on fingerprint features to predict whether each compound is Active or Inactive for a given gene target. The result was evaluated using Jaccard Similarity, Accuracy, Precision, and Recall.
